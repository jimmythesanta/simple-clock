# Simple Clock

A minimalist digital clock built with plain HTML, CSS, and JavaScript. It includes theme switching, 12/24-hour format toggle, seconds/date controls, and keyboard shortcuts.

## Features

- Live clock with smooth updates
- 12-hour / 24-hour display toggle
- Toggle seconds visibility
- Toggle date visibility
- Multiple color themes
- Saves user preferences in localStorage
- Keyboard shortcuts:
  - `T` = toggle format
  - `S` = toggle seconds
  - `D` = toggle date

## Project Structure

- `index.html` — all markup, styles, and logic in one file

## Run locally

Because this is a static page, you can simply open `index.html` in a browser.

Alternatively, serve it locally with a simple HTTP server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
